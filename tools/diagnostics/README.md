# Herramientas de Diagnóstico y Scripts Útiles

Esta carpeta contiene scripts auxiliares utilizados para pruebas puntuales, consultas a la base de datos y diagnósticos del SRI.

## Contenido de la Carpeta

- `check-last-sales.js`: Script Node.js para inspección rápida de las últimas ventas registradas en PostgreSQL/SQLite.
- `check-sri-status.js`: Consulta directa del estado de autorización de comprobantes en los WebServices del SRI.
- `query_sri_soap.js`: Cliente JS básico para enviar peticiones SOAP manuales al SRI.
- `query_sri_soap.py`: Cliente Python para inspección SOAP de respuestas del SRI.
- `fix_btn.py` y `fix_button.js`: Scripts de apoyo para mantenimiento visual UI.
